# GameShelf beta - problems and ideas

This repository holds the issues for the GameShelf beta. The code lives elsewhere; nothing here
needs to be built or downloaded.

## Reporting a problem

1. In GameShelf, open **Settings > Report a problem**. It saves a zip of the logs and settings,
   with API keys, account names and your Windows user name taken out, and shows it in File Explorer.
   It also opens the report page here with your GameShelf version filled in.
2. Say what happened and how to make it happen again.
3. Drag the zip into the **Report zip** box and submit.

You can also start a report from the **Issues** tab: **New issue > Report a problem**.

## Ideas

**New issue > Idea or request**. Please check the open issues first - a thumbs-up on an existing
one counts too.

## Privacy

Issues here are public. The report zip is made to leave out keys and names, but have a look inside
before attaching it if you want to be sure.
